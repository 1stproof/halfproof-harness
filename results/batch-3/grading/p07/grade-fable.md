# Referee report, problem 7 (Dehn twists and the Per_4 deformation space)

Reference point (author's solution): the required curve is not a "standard" pair curve. One takes the loop alpha in the deformation locus around x=y=1/2 (where v passes through f(c_1)=infinity), whose mapping class is the twist about a curve phi_alpha enclosing {v, f(c_1)}; alpha lies in the image G_0 of pi_1 of the base component, so it fixes that component. One then conjugates by a liftable element beta (a point-push of v around f^2(c_1)=1 and around infinity); gamma = beta alpha beta^{-1} is still a self-equivalence (both projections of alpha are trivial), and the group-theoretic computation in pi_1 of the complement of three concurrent lines shows no power of gamma lies in G_0. The answer is therefore the twist about phi_gamma = T_{psi_L}(phi_alpha), a twisted representative of the {v, f(c_1)} partition class. Two facts matter for grading: (a) the components of D_f are infinitely many (Hironaka–Koch), and (b) the isotopy class relative to B, not just the partition of B that a curve induces, determines the mapping class; the infinitely many isotopy classes within one partition class are exactly where the answer hides.

## Solution X

X sets up the normal form g(w)=1+alpha/w+beta/w^2 for the 4-cycle 0 -> infinity -> 1 -> lambda -> 0, derives the correct formula R(lambda) for the free critical value, and proves the three "exact square" identities (verified: R(2) = -1/24 and the factorizations check). It correctly shows that for a curve gamma enclosing {f^2(c_1), v}, f^{-1}(gamma) is a single curve double-covering gamma, that no odd power of T_gamma lifts in the pure sense, and that T_gamma^2 preserves D_f. Everything after that is wrong, and the headline result (Corollary "response to the posed problem": the problem's conclusion is false, D_f has 2 or 4 components, no twist power has an infinite orbit) contradicts both the author's solution and the published Hironaka–Koch theorem that D_f has infinitely many components. The errors: (1) Proposition "preimage" (Section 3) asserts the branch-side disc U_c contains no point of A; but f(p_1)=p_2 lies in the inner disc, so p_1 is in U_c. X's own Lemma "descend" gives U_c cap A = {p_{i-1}}, which for i=2 is {p_1}, yet the lemma's displayed formula says "empty" for this case. The conclusion (trivial on A) survives, the proof does not. (2) Theorem "puncture census" identifies the monodromy of each based puncture loop with a standard round twist (x_0^2, x_2^2, u_0 x_1, ...). A based loop has monodromy g x_i^2 g^{-1} with g depending on the transport path to the puncture; the subgroup generated by these conjugates is not the subgroup generated by the standard twists. This is precisely the mechanism in the author's solution (beta alpha beta^{-1} escapes G_0 while alpha does not), and X erases it. (3) Corollary "structural form of H" and Corollary "index and components": from H cap K contained in F with [K:F]=4, X concludes [K : H cap K] <= 4. Containment gives the reverse inequality, >= 4. The finiteness of the component set, and the whole final section, rest on this reversed inequality. (4) Proposition "content table" (c) and Corollary "answer" claim that every essential separating curve on the 5-punctured sphere is, up to isotopy, one of the finitely many "pair curves" and that there is a unique curve whose twist power preserves D_f. There are infinitely many isotopy classes of curves inducing a given partition of B; the claimed classification is false. (5) Smaller defects: the "content table" is missing from Proposition "content table" (the text reads "are: where for..."); Theorem "half-lift" is cited for a part (iii) that does not exist; Teich of the 4-punctured sphere is called H^2 x R (it is H^2). What is claimed: a disproof of the problem. What is established: the normal form, the square identities, and that the square of the twist about a {f^2(c_1), v} curve preserves D_f. The approach (bounding the index of the monodromy group by charge parity) cannot be repaired into an answer, since the true index is infinite.

## Solution Y

Y proposes gamma = a curve separating {c_1, f^2(c_1)} from {f(c_1), f^3(c_1), v}, asserts that T_gamma^2 is a self-equivalence by citing Firsova–Kahn–Selinger ("Table 1, case (6)", "Section 9, case (6)", "Note 5.4", "Lemma 5.5", "Lemma 4.2"), and asserts the infinite orbit by citing Hironaka–Koch "Prop. 5.6 and Prop. 5.8" for an element Gamma of infinite order modulo the base-component group, together with the unproved claim that Gamma "is exactly" a power of T_gamma. Nothing is proved in the document itself beyond the one-line Lemma 1 (if no power of g fixes the base component, the orbit is infinite). Errors and gaps: (1) Definition "The curve gamma" says such a curve is "unique up to isotopy relative to B". False: there are infinitely many isotopy classes of curves separating {0,1} from {infinity, rho, v}, and which one is meant is exactly the content of the problem. (2) Whether T_gamma^2 is a self-equivalence depends on how f^{-1}(gamma) distributes the points f(c_1), f^3(c_1) between the two preimage discs; Y gives no argument, only the citation. (3) The identification of Hironaka–Koch's infinite-order element with a Dehn twist about a standard pair curve is unsupported and contradicts the author's solution, in which the infinite-orbit twist is about a conjugated (twisted) curve and projects trivially to both 4-point moduli spaces, whereas Y's T_gamma projects to a nontrivial twist under the forgetful map. Solution Z, citing the same paper, describes the element as a braid word (s_2 c r_1 s_1 c r_2, Remark 4.7), not a Dehn twist. The load-bearing citation is almost certainly misattributed. (4) The file does not compile as submitted (wrapped in a Markdown code fence; f^\* in math mode). What is claimed: a complete solution. What is established: nothing beyond Lemma 1.

## Solution Z

Z works with the concrete Hironaka–Koch map f(z) = (4z-3)(z+2)/(4z^2), cycle 0 -> infinity -> 1 -> 3/4 -> 0, free critical value v = 121/96 (all verified: f' = (12-5z)/(4z^3), f(12/5) = 121/96, deck involution 6z/(5z-6), fibers over B as listed). It also gives a correct one-parameter normal form f_alpha and verifies by hand that v(alpha) - alpha = -alpha(alpha^2+alpha-1)^2/(alpha^2+alpha+1)^2, so the collision of v with c_1 has multiplicity 2 (all algebra checked; consistent with the author's formula, in which v=0 is a double root at rho^2-3rho+1=0). Theorem A: for any curve gamma_{a,v} bounding a disc meeting B in {a, v}, a in {0, 1, 3/4}, the preimage is one curve of degree 2, the preimage disc contains exactly one point of A, so T_gamma^2 lifts to T_delta, both the lift and the forgetful image are trivial in Mod(A), hence T_gamma^2 is a self-equivalence and preserves D_f. This is correct, and because it uses only the disc structure it holds for every isotopy class in the partition class. Theorem B: the square of the twist about the vanishing cycle of the v = c_1 collision lies in the base-component group E_f, so it fixes the base component. This is correct for the transported vanishing cycle, but Z glosses over the base-path dependence ("under the Hironaka–Koch marking conventions ... the specific curve gamma_{0,v}"): the statement is true for one isotopy class in the {0, v} partition class, not for "any" such curve as the notation gamma_{0,v} was defined. Z's open point (2), that "the canonical curve gamma_{0,v} does not supply the infinite orbit", therefore overreaches slightly; a twisted representative of the same partition class is not ruled out, and the author's answer is exactly such a twisted representative (of the {v, f(c_1)} class). Z states plainly that it does not produce the infinite orbit and that it does not identify Hironaka–Koch's braid element with a Dehn twist. What is claimed: a partial result (preservation half only). What is established: exactly that, correctly.
